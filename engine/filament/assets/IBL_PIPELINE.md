# SLAYER IBL pipeline

Filament 1.77 expects the environment generated by cmgen.

## Generate the stadium IBL

Place the source environment at:

assets/source/stadium.hdr

Then run:

cmgen -f ktx -s 128 -x benchmarks/filament-v0.1/assets/generated/ assets/source/stadium.hdr

The generated deployment directory contains the KTX environment plus the spherical-harmonics data.

For Android, copy the generated reflection KTX to:

benchmarks/filament-v0.1/android/app/src/main/assets/ibl/stadium_ibl.ktx

The native renderer now has the Ktx1Reader -> Texture -> IndirectLight/Skybox path.

The repository intentionally does not fabricate an HDRI. A real stadium HDRI is required for real IBL quality.

# SLAYER native runtime assets

The native Android renderer consumes validated assets generated by the CI production pipeline.

## Generated runtime files

- `models/player.glb` — packaged from the Cloudinary SLAYER player asset.
- `models/pitch.glb` — extracted/converted from the Cloudinary CC0 football field archive.
- `models/animation_library.glb` — packaged from the Cloudinary mannequin animation asset.
- `ibl/orlando_stadium/orlando_stadium_1k_ibl.ktx` — generated by `cmgen`.
- `ibl/orlando_stadium/orlando_stadium_1k_skybox.ktx` — generated by `cmgen`.
- `materials/grass.filamat` — optional compiled grass material; the renderer retains its procedural fallback when this package is unavailable.

Production source assets stay in Cloudinary and are downloaded only during the controlled asset-preparation stage. Runtime gameplay never depends on a remote first-frame download.

# SLAYER native runtime assets

The native Android renderer consumes validated assets generated by the CI production pipeline.

## Runtime 3D content

- `models/player.glb` — hero player source from the Cloudinary SLAYER catalog.
- `models/player_lod1.glb` — optional geometry LOD generated from the hero player with gltfpack.
- `models/player_lod2.glb` — optional lower-cost geometry LOD generated from the hero player with gltfpack.
- `models/pitch.glb` — extracted/converted football pitch source.
- `models/animation_library.glb` — animation reference library. The current native runtime applies clips embedded in the loaded player asset; formal retargeting remains a separate content phase.

## Lighting and PBR

- `ibl/orlando_stadium/orlando_stadium_1k_ibl.ktx` — image-based lighting generated by `cmgen`.
- `ibl/orlando_stadium/orlando_stadium_1k_skybox.ktx` — matching skybox.
- `materials/grass.filamat` — compiled Vulkan/mobile grass material.
- `materials/player_skin.filamat` — compiled Vulkan/mobile player-skin material contract.
- `materials/player_kit.filamat` — compiled Vulkan/mobile player-kit material contract.

## Quality and rendering stack

The native path targets:

- PBR materials and normal/roughness/AO maps.
- HDR image-based lighting.
- ACES tone mapping.
- TAA + FXAA where appropriate.
- GTAO contact shading.
- Bloom for HDR highlights and stadium floodlights.
- Dynamic resolution for thermal/GPU headroom.
- Day / twilight / night lighting profiles.
- Lightweight native weather path.
- Broadcast / dynamic / overview / pro / custom cameras.
- 22-player instancing with animation-rate LOD.

Final faces, kit library, multiple stadiums, crowd, advanced weather particles, ball/net detail and replay FX remain original/licensed content deliverables. Runtime never depends on a remote first-frame download.

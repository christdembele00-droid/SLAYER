# SLAYER asset manifest
Production-ready asset slots:
- players: realistic licensed/CC0 glTF/GLB models
- kits: team-specific PBR materials
- stadium: modular glTF/GLB sections
- pitch: PBR grass + line masks
- goals/nets: collision + cloth-ready assets
- crowd: instanced/VAT-ready characters
- audio: crowd, whistle, ball, boots, commentary
- animation: locomotion, contacts, tackles, saves, celebrations
Use only assets whose licenses permit redistribution in the game. Keep source/license metadata beside imported assets.

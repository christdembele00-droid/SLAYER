# SLAYER - Production graphics pipeline

Canonical native path: engine/filament.

Cloudinary -> versioned catalog -> download and validation -> GLB/PBR preparation -> gltfpack LOD and Blender conversion -> matc materials and cmgen KTX IBL -> packaged Android assets -> Filament -> Vulkan.

Cloudinary is a build-time source/distribution service. The first frame never depends on a network request.

The current catalog contains CC0 foundations and procedural originals. Final authored HD faces, complete stadium geometry, full crowd content, football-specific retargeted animation and final VFX/audio remain content deliverables.
